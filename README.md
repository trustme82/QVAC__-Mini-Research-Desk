# QVAC Mini Research Desk

A lightweight local research assistant powered by the QVAC SDK. It provides a simple web interface for submitting research questions and generating concise AI-assisted responses locally.

## Overview

QVAC Mini Research Desk is a small web application designed to demonstrate on-device AI inference using the QVAC SDK. Users can enter a research topic and receive a concise research response through a clean, minimal interface.

## Features

- Simple research query interface
- Local AI inference with QVAC SDK
- QVAC model loading with `loadModel`
- AI text generation with `completion`
- Lightweight Express server
- Responsive web interface
- Open-source project

## Tech Stack

- **Node.js**
- **Express.js**
- **QVAC SDK 0.19.0**
- **HTML / CSS / JavaScript**
